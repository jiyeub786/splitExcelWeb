설명서

이 도구는 원본 엑셀 파일의 데이터를 지정한 값(예: 지역, 부서 등)별로 걸러내어, 양식 파일 형태의 결과물 여러 개로 나눠 저장합니다. Windows + Excel이 설치된 환경에서만 동작합니다(내부적으로 실제 Excel을 자동으로 띄워서 작업합니다).

⚠ 시작 전 주의사항

  • 작업을 실행하기 전에는 열려 있는 Excel 창을 모두 닫아두세요. Excel을 자동으로 띄워서 처리하는 방식이라, 이미 열려 있는 Excel과 충돌하면 작업이 제대로 되지 않을 수 있습니다.
  • Windows의 Excel 자동화 제어가 완벽하지 않습니다. 작업이 이상하게 멈추거나 끝나지 않으면 "강제 종료"를 누르고, 그래도 남아있는 Excel 프로세스가 있다면 다시 한번 눌러주세요.
  • 수식(계산식)이 들어있는 범위를 복사/붙여넣기하는 경우, 결과가 의도한 대로 나왔는지 꼭 확인하세요. 특히 INDEX, OFFSET 같은 함수는 "암시적 교차" 때문에 예상과 다르게 계산될 수 있습니다.
  • 수식이 없는 단순 데이터라면 옵션의 "수식 경로 참조 제거"를 N으로 꺼두면 처리 속도가 빨라집니다(자세한 내용은 아래 ⑤ 옵션 참고).

① 파일 올리기

  • 원본파일: 분리할 데이터가 들어있는 엑셀 파일.
  • 양식파일: 결과물의 서식/틀이 되는 엑셀 파일. 원본파일에서 값만 지우고(수식이 있다면 수식은 남기고) 저장해둔 파일이라고 생각하면 됩니다. 원본파일을 그대로 양식으로도 쓰고 싶다면 "양식파일이 원본파일과 동일함" 체크박스를 켜면 업로드를 한 번만 해도 됩니다.

② 저장 파일명

저장 명칭/저장 일자를 입력하면 결과 파일이 {명칭}_{순번}_{대상값}_{일자}.xlsx 형식으로 저장됩니다. 원본파일을 올리면 파일명과 오늘 날짜가 자동으로 채워지니 필요하면 수정만 하면 됩니다.

③ 시트 작업 정의

원본의 어느 시트에서, 어느 열을 기준으로, 어느 범위를 복사해서, 양식의 어디에 붙여넣을지 한 행씩 정의합니다. 처리할 시트가 여러 개면 "+ 행 추가"로 행을 늘리세요.

  • 시트명: 원본파일을 올리면 자동완성으로 실제 시트 이름이 뜹니다.
  • 필터 열: 분리 기준이 되는 열을 A, B, C처럼 문자로 입력합니다.
  • 복사 범위 / 붙여넣기 위치: 직접 A1:D500처럼 입력해도 되고, "선택" 버튼을 누르면 실제 데이터를 보면서 셀을 클릭(또는 드래그, 첫 셀 클릭 후 Shift+끝 셀 클릭)해서 지정할 수 있습니다. 데이터가 아주 길면 시작 셀/열만 잡고 "마지막 행 확장" 버튼으로 끝까지 한 번에 늘릴 수 있습니다. 예를 들어 원본에서 A2:D500을 복사한다면, 양식에는 보통 A2에 붙여넣습니다(같은 시작 행/열에 붙여넣는 것이 일반적입니다).

④ 분리 대상 목록

결과물을 나눌 기준값들을 한 줄에 하나씩 입력합니다(예: 서울, 경기, 부산). 직접 입력하는 대신, 원본파일의 시트명 + 열을 지정하고 "추출"을 누르면 그 열의 고유값을 자동으로 뽑아 채워줍니다.

⑤ 옵션

  • 줌 레벨(개요시트 / 나머지 시트): 결과 파일을 열었을 때의 확대/축소 비율(%)입니다. 첫 번째 시트와 나머지 시트를 따로 지정할 수 있고, 0으로 두면 줌을 건드리지 않고 원래 값 그대로 둡니다.
  • 눈금선 제거: 결과 파일의 셀 눈금선을 안 보이게 할지 여부입니다.
  • 수식 경로 참조 제거: 엑셀은 다른 파일에서 수식을 복사해 붙여넣으면 그 수식이 원본 파일의 경로를 계속 참조하게 되는데, 이 옵션을 켜면(Y) 그 경로 참조를 일괄로 지워줍니다. 다만 이 작업 자체가 시간이 걸리므로, 애초에 수식이 없는 데이터라면 N으로 꺼두면 처리 속도가 빨라집니다.

잘 모르겠으면 기본값 그대로 두어도 됩니다.

⑥ 실행

  • 테스트(1건): 분리 대상 목록 중 첫 번째 값만으로 먼저 결과를 확인해볼 수 있습니다. 설정이 맞는지 확인할 때 먼저 눌러보세요.
  • 작업 시작: 분리 대상 목록 전체를 처리합니다.
  • 실행 중에는 아래 "실행 로그"에서 진행 상황이 실시간으로 표시됩니다. 잘못 실행했다면 "취소"(협조적 취소 — 진행 중인 시트 작업까지만 마치고 중단)를 먼저 눌러보고, 그래도 Excel이 응답하지 않으면 "강제 종료"(현재 작업을 멈추고 Excel 프로세스 자체를 강제 종료 — 이 웹 버전에서는 버튼 한 번으로 둘 다 처리됩니다)를 누르세요. 강제 종료는 지금 실행 중인 작업만 멈추는 것이며, 이 페이지나 서버 자체가 꺼지는 것은 아닙니다.
  • 완료되면 "결과 다운로드" 버튼으로 결과 파일들을 zip으로 받을 수 있습니다.

설정 저장/불러오기

지금까지 입력한 내용을 JSON 파일로 "다운로드"해두면, 다음에 "불러오기"로 그대로 다시 불러와 재사용할 수 있습니다. 같은 종류의 작업을 반복한다면 미리 저장해두는 것을 추천합니다.
